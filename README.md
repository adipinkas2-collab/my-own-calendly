# רגע — יומן אישי

גרסה ראשונה בעברית, מותאמת לטלפון ולמחשב: יומן חודשי, הגדרת זמינות, קביעת פגישה וביטול פגישות. שעות מוצגות לפי אזור הזמן של הדפדפן, עם מניעת חפיפות.

## הפעלה

נדרש Node.js 20.19+ או 22.12+.

```sh
npm ci --cache /tmp/calendly-npm
npm run dev
```

```sh
npm test
npm run build
```

הנתונים נשמרים ב־localStorage בדפדפן הנוכחי בלבד. אין כרגע שרת, משתמשים, שליחת אימייל, סנכרון ליומן חיצוני או קישור ציבורי להזמנות. מחיקת נתוני הדפדפן מוחקת את הפגישות. אין להזין מידע רגיש בגרסת ההדגמה.
